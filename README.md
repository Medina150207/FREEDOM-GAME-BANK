# FREEDOM GAME BANK — ONE BAD BET

**Интерактивный ретро-финансовый триллер / учебный прототип.**

Ты — брокер за ночным терминалом. Клиент передаёт тебе $100 000 виртуальных денег, а его опасные партнёры требуют отчёт. Решай, сколько вложить в Apple, Microsoft, NVIDIA и Tesla, переживи вымышленный рыночный шок и докажи, что можешь самостоятельно анализировать концентрацию риска.

## Запуск
- **Без установки:** скачай репозиторий через **Code → Download ZIP**, распакуй и открой `index.html` в браузере.
- **GitHub Pages:** `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`. После развёртывания GitHub покажет URL опубликованной игры.

## Файлы
- `index.html` — основной экран.
- `styles.css` — оригинальный CRT/ретро-терминал, зелёная палитра, адаптивная вёрстка.
- `game.js` — все игровые сцены, расчёты и логика решений.

## Что уже работает
1. **Контракт:** эмоциональная завязка; игрок отвечает за чужие *виртуальные* деньги.
2. **Досье:** четыре знакомых публичных компании (Apple, Microsoft, NVIDIA, Tesla).
3. **Первое распределение:** произвольный портфель + письменное объяснение до результата.
4. **Вымышленный шок:** Apple −40% и прямые последствия для портфеля.
5. **Разбор:** пользователь объясняет, почему решение повлияло на размер потери.
6. **Машина времени:** повторное распределение при *том же* событии и сравнение ущерба.
7. **Два будущих:** Apple +30% вместо падения; объяснение, почему прибыль не отменяет риск.
8. **Новая миссия без подсказки:** другой портфель на $200 000, NVIDIA, возможность изучить его состав и принять решение без навязанного ответа.
9. **Итог:** разбор принятого решения, вымышленное событие NVIDIA −35%, сохранение протокола в JSON.

Изменения цен не являются настоящими рыночными данными. В учебном сравнении остальные позиции условно неизменны для изоляции одной переменной.

## Для конкурса: проверка эффекта
**Гипотеза:** игровые последствия и повторная попытка повышают долю пользователей, которые через 7 дней замечают концентрацию риска в новой задаче без подсказки, по сравнению с классическим уроком.

**Основная метрика:** процент успешных самостоятельных решений через 7 дней, по заранее подготовленной рубрике и с независимой проверкой объяснения.

**Другие метрики:** просмотр состава портфеля до действия; пересмотр ошибочного решения с объяснением; завершение игры; возврат к аналитическим функциям сервиса в сопоставимых условиях.

**Заградительная метрика:** доля самоуверенных ошибок — высокая уверенность (80%+) при неправильном обосновании решения по независимой рубрике. Внутриигровой сигнал «не открыл портфель» — лишь косвенный маркер, *не* доказательство ошибки.

**Дизайн проверки:** рандомизированное сравнение A (урок + тест) и B (игровой сценарий), опционально C (та же практика без игры); учёт исходного опыта, одинаковые приглашения и условия, фиксированные виртуальные события, слепая ручная оценка ответов и регистрация выбывания.

Сам прототип **не проводит** эксперимент автоматически и **не оценивает** объяснения как правильные или неправильные с помощью ИИ.

Независимый учебный прототип, вдохновлённый зелёной финансовой эстетикой. Это **не официальный продукт Freedom Bank / Freedom Broker**. Все средства виртуальные, любые угрозы клиентом — вымышленный художественный сюжет без реального насилия, все изменения цен придуманы. Инвестиционных рекомендаций нет.
