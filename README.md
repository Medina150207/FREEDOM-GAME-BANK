# Freedom Game Bank 🎮

Обучающий инвестиционный симулятор «Что будет, если…».

## Запуск
1. Нажмите Code → Download ZIP в GitHub.
2. Распакуйте архив и откройте index.html в браузере.
3. Проходите сценарий: выбор → событие → разбор → повторная попытка → финальная миссия.

Никаких библиотек, сервера или API-ключей не требуется.

## В игре
- Виртуальные 100 000 единиц и распределение портфеля.
- Акции вымышленных компаний Аврора и Вектор, резерв.
- Сценарии падения Авроры на 40% и роста на 30%.
- Пересчёт убытка, сравнение решений и новая миссия Орбита.
- Свободные текстовые объяснения и выгрузка результатов в JSON.

## Публикация сайта
GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Ограничения
Это учебный MVP с виртуальными средствами, не инвестиционная рекомендация.
Проверка текста по ключевым признакам является только предварительной и не заменяет оценку человеком.
Сервер и база данных ещё не подключены.
